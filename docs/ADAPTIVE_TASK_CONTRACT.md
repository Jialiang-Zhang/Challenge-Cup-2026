# 自适应 Task Contract 与候选恢复门

## 1. 目标

这一层解决两个不同问题：

1. 题面没有可靠元数据时，怎样识别方向、题型和必须交付的答案组成部分；
2. 模型已经完成数学推导但没有完整输出 XML 协议时，怎样避免把“协议不完整”误判为“数学内容截断”。

画像器不调用模型，不消耗竞赛 API 额度。所有结论都进入 `TaskContract` 和 `trace`，可离线回放。

## 2. 非强制题型画像

`agent/task_profile.py` 输出：

- `mode`：`choice`、`fill`、`true_false`、`proof`、`multipart`、`solve_all`、`calculation` 或 `open_response`；
- `confidence`：当前题型证据强度；
- `alternate_modes`：存在重叠信号时保留最多两个备选；
- `choice_count`：仅在题面明确写出“选择两个”“单选”等约束时设置；
- `blank_count`：只统计明确空格标记；
- `part_count`：识别编号小问；
- `obligations`：最终答案必须满足的覆盖义务；
- `ambiguity_flags`：低信号或多种题型重叠时显式记录歧义。

没有足够证据时返回 `open_response`，不会强制猜测选择、填空或证明题，也不会猜测多选题应选几个。

## 3. 十八方向 Top-2 软路由

`agent/routing.py` 对十八个竞赛方向计算可解释分数，返回一个主方向和最多两个次方向：

1. 离散数学
2. 数值分析
3. 测度积分
4. 微分几何
5. 概率论
6. 抽象代数
7. 随机过程
8. 复分析
9. 常微分方程
10. 统计推断
11. 泛函分析
12. 线性回归
13. 偏微分方程
14. 非基础及进阶课程
15. 高等代数
16. 运筹学
17. 数学分析
18. 拓扑学

路由采用“通用信号 + 强领域锚点”，避免把“稳定域”中的“域”误判成抽象代数，也允许数值 PDE、概率与随机过程等交叉题同时保留两个方向。

## 4. Answer Obligations

画像结果被转换成可检查的答案义务：

| 义务 | 触发条件 | 确定性检查 |
|---|---|---|
| `choice_letters` | 明确选项结构 | 必须提取到选项字母 |
| `choice_count:n` | 题面明确选择数量 | 去重后的选项数必须等于 `n` |
| `blank_count:n` | 明确空格数量 | 答案值数量必须等于 `n` |
| `binary_verdict` | 判断题 | 只接受规范真假结论 |
| `multipart_count:n` | 多小问 | 小问标签或独立 Claim 覆盖 |
| `proof_chain` | 明确要求证明 | 检查证明长度与推理连接信号 |
| `all_solutions` | 要求全部解 | 检查穷尽性声明，并交给红队攻击 |

选择数量、填空数量和二元结论不满足时属于硬失败；证明完整性和“全部解”难以仅靠字符串决定，因此确定性检查只给出 `PASS/UNKNOWN`，再由对抗审查处理，不伪造数学否决。

## 5. 协议恢复与真实截断分离

`agent/parsing.py` 分开记录：

- `protocol_complete`：所需协议标签是否闭合；
- `truncated`：数学内容是否疑似真正中断；
- `recovery_source`：恢复结论来自明确标签、断言还是 `\boxed{}`。

缺少协议标签的候选只有同时满足以下条件才可恢复：

1. 存在强结论来源，不能只取任意最后一行；
2. 文本有完整收尾，不以连接词、运算符或半截句结束；
3. 证明题必须有足够正文和推理连接信号；
4. 单独的 `<FINAL_CANDIDATE>`、占位符或无结论长推理仍然视为硬截断。

恢复会生成 `protocol_recovery` 证据并写入 trace，不能静默改变候选。真正截断仍由 `truncation` 硬证据否决。

## 6. 112 题离线画像回放

在公开 112 题上仅运行画像器、不调用模型：

- 十八方向 Top-1：`95/112`；
- 十八方向 Top-2：`112/112`；
- 识别出 7 道选择、1 道判断、1 道双空填空；
- 数值分析 idx25：主方向为数值分析，识别 3 个证明子任务；
- 常微分方程 idx90：主方向为常微分方程，附加证明链义务。

这些数字只验证路由覆盖与答案形状，不代表数学答案正确率。正式收益仍需在独立结果分支运行模型 benchmark 并进行人工数学审计。

## 7. 回归不变量

- 画像器不得读取 `answer`、`subject` 或 `source`；
- 题型低置信度时不得升级为硬格式约束；
- 缺少标签不自动等于数学错误；
- 任意恢复必须保留来源并通过现有证据门；
- 占位符、答案数量不符和真实截断仍不能进入 Transaction Commit。
